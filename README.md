# Wanderlust

A full-stack Airbnb-inspired travel accommodation platform built with Node.js, Express, MongoDB, EJS and Cloudinary.

## 🚀 Live Demo

[Visit Wanderlust](https://wanderlust-wo2o.onrender.com)

## 💻 Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Passport.js
- Cloudinary
- Bootstrap
